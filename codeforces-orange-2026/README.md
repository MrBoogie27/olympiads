# Планы обучения для достижения оранжевого ранга на Codeforces

**Период**: Август 2026 - Апрель 2027 (8 месяцев)  
**Текущий рейтинг**: 1757  
**Целевой рейтинг**: 2100+ (оранжевый)  
**Время в неделю**: 5 часов (вт/чт 18:30-21:00) + суббота 12:00

---

## Структура папок

### `/code/`
Реализации алгоритмов и решения задач на C++
- `week1-sorting/` - Быстрая сортировка, слияние
- `week2-binary-search/` - Бинарный поиск
- `week3-graphs/` - Алгоритмы на графах
- и т.д.

### `/resources/`
Ссылки на полезные материалы, конспекты, шаблоны
- `templates.cpp` - Полезные шаблоны для Codeforces
- `algorithms-links.md` - Ссылки на теорию

### `/progress/`
Отслеживание вашего прогресса
- `all-topics.csv` - Обзор всех 31 недель
- `training-schedule-full-31-weeks.csv` - **ПОЛНОЕ РАСПИСАНИЕ на все месяцы** с конкретными ссылками на задачи
- `training-schedule-august-september.csv` - Подробное расписание на август-сентябрь (опционально)
- `weekly-progress.csv` - Таблица для отслеживания прогресса

## План по месяцам

1. **Август-Сентябрь**: Основные алгоритмы (сортировка, бинпоиск, графы)
2. **Сентябрь-Октябрь**: Продвинутые графы и динамическое программирование
3. **Октябрь-Ноябрь**: Структуры данных (segment tree, Fenwick)
4. **Ноябрь-Декабрь**: Алгоритмы на строках
5. **Январь**: Теория чисел, комбинаторика, геометрия
6. **Февраль-Март**: Интенсивная контестная практика
7. **Апрель**: Финальный спринт

## Как использовать этот проект

1. Откройте расписание в Google Sheets (ссылка выше)
2. Каждую неделю ознакомьтесь с темой и ресурсами
3. Решайте задачи из расписания
4. Сохраняйте свои решения в папке `/code/`
5. Отслеживайте прогресс в `/progress/`
6. Участвуйте в контестах и дорешивайте

Удачи! 🚀
