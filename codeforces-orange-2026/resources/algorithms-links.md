## Инструменты и окружение

### Компиляция и тестирование

```bash
# Компиляция с оптимизацией
g++ -O2 -Wall solution.cpp -o solution

# С дебагом (для локального тестирования)
g++ -g solution.cpp -o solution

# Запуск
./solution < input.txt > output.txt

# С таймингом
time ./solution < input.txt > output.txt
```

### Локальное тестирование

Сохраняйте примеры в файлы:
- `test1.txt` - входные данные
- `test1.out` - ожидаемый выход

Проверяйте:
```bash
./solution < test1.txt > myout.txt
diff myout.txt test1.out
```

### IDE/Редакторы

- **VS Code** + C++ extension - Рекомендуется
- **CLion** - Платная, но мощная
- **Code::Blocks** - Бесплатная и простая
- **Sublime Text** - Легкая и быстрая

## Как эффективно учиться

1. **Прочитайте теорию** в e-maxx или CP-Algorithms
2. **Посмотрите примеры кода** в репозитории (папка `code/`)
3. **Напишите реализацию сами** без подглядывания
4. **Решайте задачи** постепенно усложняя
5. **Анализируйте** код других участников
6. **Делитесь ошибками** - учитесь на них
7. **Участвуйте в контестах** - это ускоряет обучение

---

## Советы по быстрому обучению

- **Не зацикливайтесь на задаче**: Если 20 минут не решаете - смотрите разбор
- **Код других**: Смотрите solutions на Codeforces, учитесь из них
- **Контесты**: Участвуйте в live контестах, это ускоряет обучение
- **Разнообразие**: Решайте разные типы задач, не только любимые
- **Отслеживание**: Ведите список решенных задач (что изучили)
- **Перерывы**: Отдыхайте между интенсивными сессиями
- **Системность**: Следуйте плану, не скачите между темами
